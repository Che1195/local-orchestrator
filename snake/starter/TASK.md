# Snake evaluation: common product contract

Build an original, playable Snake-style arcade game as one self-contained HTML file that I can open directly in my browser. Use inline CSS and plain JavaScript, with no libraries, downloads, external assets, or server. Use a responsive 20-by-20 canvas board, a dark arcade style, a green snake, and clearly distinct food. Include labeled score and best score, short instructions, a Start / Restart button, a separate Pause / Resume button, and large on-screen direction buttons for touch. Support arrow keys and WASD for steering and Space for pause. The game should begin in a ready state. Eating food grows the snake and gradually increases speed. Walls and the snake body end the game. Keep the implementation simple and reliable: one game loop, clean state reset on restart, no 180-degree reversal even with rapid key presses, food only on empty cells, and a win state when the board is full. Pause when the tab loses focus. Guard localStorage access so storage restrictions cannot break play. Make the layout fit a phone, preserve browser zoom, use native buttons with visible focus, and avoid intercepting Space when a button is focused.

Use your actual file-editing tool to save the COMPLETE HTML as src/snake.html in this workspace. Do not print the HTML or a proposed tool call instead of writing the file. Do not read other implementations. Do not run or test the game; Che will test it himself. No browser, server, build, package installation, or network requests. Reading your own files and reasoning about your code are allowed. After saving, report the saved absolute path. If saving fails, report the actual error; do not claim success.
